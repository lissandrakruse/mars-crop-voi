# Within-study source analysis

Run `pip install numpy pandas scipy matplotlib` then `python research/strengthen_analysis.py` from the repository root. The source is `data/wamelink2014_pots.csv`; endpoint is at least three living plants at day 50. Seed 20261016; 20,000 complete-block bootstrap replicates. Tables are frozen outputs from 16 October 2026.

The eight exact paired contrasts are retrospectively declared secondary analyses with Holm adjustment. Block bootstrap intervals are descriptive. Validation holds out each of 20 complete source-study blocks; it does not test an environmental-distance kernel, external transfer, spaceflight, or actual Mars outcomes. Bootstrap uncertainty is conditional on existing out-of-fold predictions, not full repeated cross-validation uncertainty. All 14 species are the main internal benchmark; the original four crops are secondary illustrations. See the code for all output tables and figures.

Figures generated by this script are analysis outputs. Journal-ready CMYK EPS files are maintained in the manuscript package. Font availability may change appearance without changing numeric results.
