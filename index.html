What this method establishes

Linear programming bounds a conditional probability over 16 possible worlds. Greedy selection adds the empirical constraint that most reduces interval width at each step. Endpoint pruning can avoid solver calls without changing the bounds.

Interval width reduction is not full value of information. Decision alternatives, utilities, observation likelihoods and measurement costs are still needed. These bounds are not sampling confidence intervals. This is an independent adaptation of the methodological approach discussed previously, not a verified reproduction of the earlier implementation.
